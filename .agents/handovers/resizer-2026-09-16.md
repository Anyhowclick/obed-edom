## 3. Gate lessons

- **Preview cache is per-worktree.** `baseline.cache_root` resolves `find_repo_root()/.cache`. A
  gate worktree without `.cache` symlinked to the shared cache silently falls back to different
  roster packing on Gold slides 11/12 (90 `role=list` rows drift). Link `.cache` explicitly, or
  export `OBED_EDOM_CACHE_DIR`.
- **Live verify coverage is thin.** Only runs with `--validate` (09-15 baseline used
  `--no-validate`, never exercised it). Excludes every z-order-patched slide (`kindIndex`
  addressing breaks under the permutation): 9→2 slides covered on Gold, 1→0 on RAISE10 — see §4.
- **`FRONT_BLOCK_OK` is arm-B-only.** Arm A unraised (source stacking) since #136; requiring it in
  both arms was gate-code drift, not a writer regression (#145 fixed it).
- **Run launchers unsandboxed, from a pinned detached worktree** — a sandboxed shell cannot launch
  Keynote at all; never launch from a tree an agent is actively editing.
- **Keynote may already be running with zero open documents** — expected, handled by the gate's
  own pass-1 `saved=`/`closed=` check; do not quit or inspect Keynote manually over this.
