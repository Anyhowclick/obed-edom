## What merged (PR #161)

Two increments, each gated OFF by default, each live-validated in Keynote (subset 4,57,70,123 of
`Convert wall to 16x9 CGs/Full_Report_Card_Wall.key`; overall live verify PASS, source byte-identical):

1. **`OBED_OFFLINE_TEXT` — reposition autosize text.** An autosize box is offline-repositioned
   (position only, never a size) ONLY when it is **laid out** (`_natural_size` positive on BOTH axes),
   **top-anchored** (when writing `pos_y`: `_vertical_alignment == kFrameAlignTop` — stored y is the
   visual top, Δh-immune; middle/bottom drift ~Δh/2), and has a **present, non-degenerate live seed**.
   Everything else keeps missing `text-autosize` → AppleScript (~0.5px). Logic in `iwa_write._slide_edits`
   text branch + `_text_fields(position_only=True)`.
2. **`OBED_OFFLINE_MASKCROP` — origin-anchored masked crops.** The `_masked_media_fields` transform is
   already exact for any axis-aligned mask; `_is_identity_mask` had gated it to no-crop. Now, behind the
   flag, `_is_origin_anchored_mask` also admits origin-anchored crops (mask offset ~0, within-frame,
   hardened against NaN/overhang/tiny-mask scale blowup). Offset crops + rotations still refused.
3. **Read-path hardening** (`bulk_geometry.js`): `positionOf` throws on an unreadable point (was a
   silent `[0,0]`), `xyFrom` rejects NaN; `offline_write._drop_unreadable_seed_rows` drops any seed row
   with a recorded item error. This CLOSED the untrustworthy-seed residual → default-on is no longer
   blocked on that front. `e2e_run_parity` clean (only the documented LW-21 baseline edge).
4. Diagnostic: verify prints worst-offender `(slide, kindIndex, Δ)` on a FAIL.

Reviewed by Codex (text 3 rounds, masked 1) — all findings folded. 415 unit tests green.

## The hard number: conversion is tiny on this deck

Offline census (`scratchpad/coverage.py` / `mask_census.py`, gold + source decks):

- **Text: 783 of 788 boxes are autosize, but 731 (93%) are kFrameAlignMiddle; only 52 (6.6%) top.**
  On the validated subset the stricter (post-Codex) gate converted **ZERO** — the round-3 `nh>0`
  tightening defers even the few that an earlier looser gate wrote. Real-world text conversion ≤6.6%,
  often 0.
- **Masked: 128 origin crops of 1527 (gold); 646 identity already written, 715 offset (out of scope),
  38 rotated.** 2 converted live on the subset and rendered correctly (frame PASS + PNG pixel-check =
  right map region).

**Neither increment — nor both — unlocks the wall-time lever** (deleting the AppleScript fallback pass):
the majority of specs (middle text, offset crops, groups) still route to AppleScript. These are
correctness/coverage wins, not the speed win.

## Open follow-ups

- **Enable-by-default? (owner decision.)** Both flags are correct + fail-safe, but low value here.
  If enabled, roll out with `OBED_OFFLINE_WRITE=verify` first. Given ~0 text conversion, enabling
  `OBED_OFFLINE_TEXT` on this deck is nearly a no-op; `OBED_OFFLINE_MASKCROP` does a little more.
- **Middle-anchored text (the 93%, the real prize) — BLOCKED on the Δh problem.** A middle box's live
  render height differs from the soft-seed height across the pipeline's reopens, so `pos_y` (written
  against the live top) drifts by ~Δh/2. Solving it needs the FINAL render height offline, which is
  intractable per the `ta-derive` research — OR a way to make the soft-seed read reflect the exported
  render state. Worth a focused investigation only if OPEN 1 is deemed worth pursuing.
- **Masked offset crops (715/1527)** — the majority of real crops; still refused (crop redistribution
  unproven offline). A separate, harder increment.
- **group-residual (83) + group-child-scale (6)** — carried from the prior handover; need live layout.
