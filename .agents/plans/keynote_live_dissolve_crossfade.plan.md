## 0. Summary

- **Root cause (player, not host).** Keynote's export encodes a slide Dissolve as two flattened full-slide textures: the
  incoming slide at the bottom with **no animation**, the outgoing slide on top with `opacity 1→0` (EaseInEaseOut, 1.5 s on
  P2). The CSS renderer replays exactly that. Over an opaque outgoing texture this is already an exact cross-fade; where the
  outgoing texture is transparent the incoming slide shows at full strength from the first frame (pop-in). Keynote's own
  exports hide it because the outgoing texture carries a full-slide black fill. The trigger is that fill's absence, not the
  transparent page (§1.3).
- **Fix.** Three count-checked, sha-pinned, in-memory replacements (D1–D3) appended to `_MM_OPACITY_REPLACEMENTS`. For a
  transition whose layer tree is exactly the Dissolve shape (topology, identity 2D geometry, no media flags) and only when the
  browser supports the blend, the player builds the transition from a **copy** of the export tree in which the incoming leaf
  starts at opacity 0 and carries the mirror animation `0→1` (generated by the player's own keyframe code, started in the
  same style pass), and both leaves composite with `mix-blend-mode: plus-lighter` inside an `isolation: isolate` container.
  **Fade and blend succeed or fail together**: if the blend cannot be installed after the DOM is built, the incoming leaf is
  restored to stock before the old slide is removed. Result: premultiplied `(1−e)·P_out + e·P_in`.
- **Measured** (headless Chrome 154, transparent page, correctly stripped PDFs; rev 2 bytes, §8). P2 2→3 (e9b2fad4): model
  residual ≤ 1.2 LSB, overlap α 255, incoming α = 255 − outgoing α, one shared `startTime`, `in = ease-in-out(t/1.5 s) ± 1e-6`;
  DSK deck 5→6 on 17c0c938: ≤ 1.5 LSB, same. Nulls (stock) pop in (residual 206 / 205). KB (mirror fade without the blend):
  overlap α 191 at e = 0.53 as predicted. Opaque-texture controls (Keynote's black-filled PDFs): stock ≤ 0.7 LSB, patched
  ≤ 1.2 LSB, on/off at matched progress ≤ 1.5 LSB. Software compositing (rev 1 bytes, exploratory): 2.7 LSB.
- **Scope.** Every output. Algebraically identical to stock wherever stock was already right; measured browser difference
  there ≤ 1.5 LSB (one take; DX-1 re-measures it, §2). Only `apple:dissolve` is in scope; the `none` cut is a follow-up.
- **Switch.** Recommended: the existing `mm_opacity` switch (one rollback; precedent hand-back 2a). `RUNTIME_VERSION` stays 2;
  `off` stays today's bytes.
- **What it does not cover.** On S2, held movies paint outside the cross-fade (§6.2); owner question 4.

## 2. Arithmetic (premultiplied RGBA, 0..1; e = eased progress, outgoing opacity o = 1 − e)

- **Stock:** `C = o·P_out + (1 − o·α_out)·P_in`, `α = o·α_out + (1 − o·α_out)·α_in`.
  - `α_out = 1`: `C = (1−e)·P_out + e·P_in` — already the cross-fade.
  - `α_out = 0`: `C = P_in` from the first frame (the pop-in).
- **Two plain opposite fades (rejected):** where both are opaque, `α = 1 − e + e²` = **0.75 at e = 0.5** (the dip; §7).
- **Fix:** the container is an isolated group (starts transparent, Compositing §3.2). Incoming, opacity e, `plus-lighter` onto
  zero = `e·P_in`; outgoing, opacity 1 − e, `plus-lighter` (`co = min(1, αs·Cs + αb·Cb)`, `αo = min(1, αs + αb)`) gives
  `G = (1−e)·P_out + e·P_in`, `α_G = (1−e)·α_out + e·α_in`. **No clamping ever**: each premultiplied channel ≤ its α and
  `(1−e)·α_out + e·α_in ≤ 1`. `G` composites source-over onto whatever lies below the container. Over black, `G`'s colour =
  the two slides rendered on black, cross-faded = Keynote's look.
- **Preconditions of this proof**, enforced by the predicate (§3.2): exactly two texture leaves; no video or poster layer (the
  player attaches `<video>` elements only to layers it marks via `objectID`/video flags, `NB.setVideoLayer`); identity 2D
  geometry on the container and leaves (so flattening by the grouping properties moves no pixel, CSS Transforms 2 §7.1).
- **Endpoints exact:** e = 0 → incoming opacity 0 → `G = P_out`; e = 1 (`fill both`) → outgoing opacity 0 → `G = P_in`.
- **8-bit.** Each blended layer renders to an RGBA8 premultiplied surface; two roundings plus PNG un/re-premultiplication.
  Measured model residual 1.2–1.5 LSB GPU, 2.7 software (§8). Gate τ = 4 LSB (§9.1).
- **Opaque textures.** Where `α_out = 1` stock and fix are **algebraically identical**. Browser level, one take each (§8):
  on/off differ by ≤ 1.51 LSB max (p99.9 1.22) at matched eased progress; rev 1's "≤ 1 LSB" was wrong. DX-1 re-measures it
  every round (report-only, bound 2 LSB).

**Isolation.** `plus-lighter` sits on the two leaf divs; their backdrop is the container group only (a stacking context through
`-webkit-transform`, plus explicit `isolation:isolate`). The blend never mixes with the page background, the host hide
(`#body` opacity is an ancestor; screen mode's `#obed-output-black` is a fixed sibling on top), the GL canvas (removed with the
outgoing DOM in the same task), or anything the continuity core inserts (`#body` or the **live** slide's layers, never the
transition container). Isolation prevents contamination; it does **not** make an independently painted overlay take part in
the fade (S2, §6.2). **Stacking:** DOM order and z-index unchanged; both leaves blended, so the result is order-independent.

### 3.2 How it works

- **Faithful or unchanged.** `__obedDissolveLayer` returns the export's own object (stock path) unless: the effect is a
  `transition` named `apple:dissolve`; `CSS.supports` accepts `mix-blend-mode: plus-lighter` and `isolation: isolate`
  (**preflight before any copy**); the tree is exactly root → one container → two textured leaves without sublayers, root and
  container without texture or animation; container and both leaves carry no `objectID`, no `isVideoLayer` /
  `isWebVideoPosterLayer`, no 3D `transform`, identity `affineTransform`, rotation 0, scale 1, opacity 1, not hidden; both
  leaves have an identity `sublayerTransform` (the container's perspective term is allowed: it acts only on the leaves' identity
  transforms); the incoming leaf has no animation; the outgoing has exactly one `opacity` animation `1→0` without
  `keyTimes`/`path`/group. Anything else, or a throw, is stock. Timing, curve, `fillMode`, `beginTime` and custom control points
  are **copied**, so the mirror goes through the same `WB` code. All 42 on-disk dissolves match; 21 near-misses stay stock (§8).
- **Copy, never mutate.** Shallow copies along root → container → incoming; everything else is shared read-only.
  `UC.script.events` (read by the hook and the continuity runtime) is untouched, so a replay patches again identically. The
  flag lives on the per-play `yB` instance.
- **Incoming invisible from DOM insertion.** `initialState.opacity 0` makes `addNode` write `opacity:0` on the incoming layer
  div at render; `applyCssAnimation` sets it to 1 and starts the wrapper at keyframe 0% (opacity 0) in the same task as the
  outgoing's start. This covers the render→animate gap and an automatic transition's delay.
- **Fade and blend fail together.** `__obedDissolveBlend` runs after `draw`, before `removeChild`, in the same task. It sets
  the three styles and reads each back (an unsupported value is dropped by the style setter). If any node is missing, any
  value does not stick or anything throws, it **restores stock** before the old DOM is removed: the incoming leaf's
  `cssAnimationRules` is emptied (so `animate` never starts the mirror), its layer opacity goes back to 1, the three styles are
  cleared, and the flag is cleared. What remains is an unused wrapper div and keyframe rule, which the player's own cleanup
  removes; pixels are stock. It never leaves a mirrored fade without the blend.
- **One clock.** Both keyframe rules are created by `WB` and started by one `applyCssAnimation` loop: measured identical
  `startTime` and `in + out = 1 ± 1e-6` at every rAF.
- **GL transitions and builds never reach it**: D2 is inside the base-layer branch; GL names fail the name test; builds go
  through `renderEffect`. Every new name carries `__obed`/`obed` (0 occurrences in either stock player); strict-mode safe.

### 3.3 Paths

Advance, completion (`fill both` holds `G = P_in` until the T + 0.1 s hand-off), replay, queued advance/skip during the
dissolve, interruption by go-to or back, hide/show, an automatic dissolve with a delay, loop wrap and end of show are each one
row of DX-1's lifecycle scenario (§9.1), which checks final pixels and the removal of the transition DOM and its keyframe rules.
The patch adds no state beyond the per-play copy and flag.

### 3.4 Alternatives rejected

- **WAAPI / CSS on the incoming DOM only:** a second clock and our own cleanup.
- **Mirrored fade without `plus-lighter`:** the 0.75 dip (KB arm).
- **2D canvas `lighter` / WebGL per frame:** far larger surface.
- **Host-side CSS:** the layer ids are per-play; the incoming animation still needs the player.
- **Alpha-only patch:** the trigger is the texture, not the page (§1.3).
