## 2. Final module design (deltas from rev 1; restated in full where corrected)

### 2.0 G1b — three fields on the flag-on entry (`live_continuity.py`, new flag-on sha)
The `glReplay` runtime entry gains, in this order after `opacityOverrides`:
- `instanceId: str` — `f"{asset}#{index}"`, `asset` = the normalised asset key (== `movies[movieKey].assetKeys[0]`), `index` = 1-based position of the destination instance in `slide_instances[to_player_index][asset]` (DOM order, same list the probe reads). Fixture: `"untitled.mov#1"`.
- `instanceRect: {x, y, w, h}` — the destination instance's `_movie_rect` as the same float dict `slide_instances` stores (fixture `{109.35…, 795.04…, 951.54…, 267.62…}`, exact floats, no rounding). The probe compares with `===` after `float()` (`live_continuity_probe.py:1640-1646, 340`), so bytes must match `slide_instances`.
- `movieSlot: int` — the movie's index in `slotSizes/slotRects`, i.e. the carried instance's position in the SOURCE slide's transition draw order (`slotSizes`/`slotRects` come from the source slide's effect; fixture 3, `slotRects[3] == [105.12, 790.85, 960, 276]`). NOT the destination-slide slot (`_overlap_refusal`'s reading gives 5 there and would refuse). S0 captures it at derivation time as `gl_replay_slot`. `to_runtime` refuses (`Unsupported`) when `movieSlot` is not `< len(slotSizes)` or `instanceRect` is not four finite floats.
`QUALIFIED_PLAN_SHA256` replaces the flag-on entry (`2ac48f11…`) with the new sha; `GL_REPLAY_RUNTIME_PLAN_SHA256` and `EXPECTED_GL_REPLAY_RUNTIME_PLAN` in `tests/test_live_continuity.py:2612-2640` move with it. The flag-off sha, P2 injected plan and every flag-off byte are untouched (G1 decision B). `CONTINUITY_VERSION` unchanged.

### 2.1 Install (IDLE)
As rev 1, plus: the MutationObserver observes `document.documentElement` `{childList, subtree}` from install (never `#stage`, which is parsed later); a removal record whose removed node is, or contains, the armed canvas ⇒ `canvasRemoved`. Also assert at ARM-PRE that `canvas.width === __OBED_CONTINUITY_INFO__.authoredWidth && canvas.height === authoredHeight` (backing store 1920×1080 at every viewport, F7) else `canvasShape` — this is what makes authored px ≡ drawing-buffer px for every ROI below. Wrapper hot path unchanged (one integer test). `WebGL2RenderingContext` wrapped when present.

### 2.2 ARM-PRE (`currentHashNum() === atScene − 1`, the whole source-slide dwell)
Requirements, each polled on rAF while in ARM-PRE, none a stand-down until a context exists: seam present (`runtimeSeamAbsent`), `window.__obedLive` present (`settleSignalAbsent`), `typeof HTMLVideoElement.prototype.requestVideoFrameCallback === 'function'` (`rvfcUnavailable`). On the first `getContext('webgl'|'webgl2')` while ARM-PRE: canvas id `/^\d+-canvas$/`, connected, size == authored (`canvasShape`); record from its first `clear`. Poster = the first upload on that context with signature `{srcType: canvas, w×h == slotSizes[movieSlot], RGBA/UNSIGNED_BYTE, flipY: true, premul: true}`; a second DISTINCT texture matching the signature at any time before ARM-POST ⇒ `posterAmbiguous`. Per-`clear` upload of `seam.carried(movieKey).video` (null ⇒ `assetUnbound`; `readyState < 2` ⇒ `videoNotReady`) into the poster texture, `replaying++`, harness `uploadInto` save/restore. Ring buffer: current segment + one retained, cap 512 calls/segment (`frameNotDelimited` on overflow).

### 2.3 Settle and ARM-POST (measured rule)
`settled` ⇔ (a) `window.__obedLive.snapshot().ready === true` observed on a rAF tick after recording began, AND (b) the last player GL call is ≥ 3 rAF ticks old (≈50 ms; measured gap between last frame and `ready` = 99.8 ms, max intra-move clear gap 32.7 ms), AND (c) `snapshot().sceneId === atScene − 1` (`sceneMismatch` otherwise — the measured 1-based-hash convention; a player that changes it fails closed). The hash flip to `atScene` follows ≈100 ms later and is NOT waited for. Record `settleGapMs = t(ready) − t(lastClear)` and `settleToHashMs` in `stats()` (report-only). Then, as rev 1: last segment must be `clearColor,clear`-delimited and non-empty; poster snapshot via FBO (`posterUnreadable`); marker swap (`occlusionTooHigh` > 50 %); restore; baseline read; the opacity proofs of rev 1 §2.3 unchanged (count/uniforms/mixfactor/size/mvp/rest-opacity/ablation/identity, per slot, never a stand-down; MVP decoded against `slotRects[i]` within 1 px; ablation bbox within grid step + 2 px). Capture `progOpacityBefore[i]` for every draw.

### 2.4 LIVE
As rev 1. Handle published on the first successful tick with `sceneId = window.__obedLive.snapshot().sceneId` frozen at publish (== `atScene − 1`), `instanceId`/`rect` = the G1b fields verbatim (`rect` as `{x,y,w,h}` floats), `canvasId = canvas.id`, `epoch` incremented on every record. Band ROI = `instanceRect` mapped to drawing-buffer px exactly as the harness `setRects.map` does (`alt-perclear/js.py:167-176`, y flipped, rounded); control = `CONTROL_PATCH_PX` (40) square inset `CONTROL_INSET_PX` (4) at the canvas top-left; `green` per owner decision D1 (§5). `sample(n)`: n distinct ticks — rVFC while playing, rAF-driven replay+read while paused (no upload; the texture holds the last frame); `t = performance.now()` strictly increasing. `pause()` = `seam.setKeepWarm(v, false)` then `v.pause()` (awaited); `resume()` = `v.play()` then `setKeepWarm(v, true)`.

### 2.5 STANDDOWN (synchronous, ordered)
1. Stop the loop. 2. Write-back: for every program we issued an override on: `useProgram(prog)`, `uniform1f(loc, progOpacityBefore)`; then restore `getParameter(CURRENT_PROGRAM)`; skipped only when `isContextLost()` is true; any thrown/`getError() !== 0` ⇒ reason `writebackFailed` (recorded in addition to the triggering reason). **When the trigger is an unflagged player call, steps 1–2 run inside the wrapper BEFORE `orig.apply`.** 3. Restore the poster (skipped on context loss). 4. `setKeepWarm(v, true)` + `play()` if we paused it. 5. `delete window.__OBED_GL_ORACLE__`. 6. `seam.release(movieKey, {rect: slotRects[movieSlot]→{x,y,w,h}})`; its `{ok, reason}` goes into the `glreplay-handoff` note. 7. Notes: `glreplay-standdown {reason}` (or `glreplay-handoff` for `canvasRemoved`) into `__OBED_GL_REPLAY__.events` and `seam.note(...)`. `mutationScanMs` report-only (the observer-callback scan time; `MutationRecord` carries no timestamp, so the real mutation→stand-down latency is an S3/CDP measurement only — arming §9 already lists that bound as untraceable in-page). No re-arm on the same context; the next Magic Move's new context re-enters at ARM-PRE only if a later `glReplay` boundary exists (v1: never — one boundary).

**Amendments from the Q3 soak (S3 r2, shipped in `f4905aaf`):** LIVE is driven by ONE loop — rVFC while video frames arrive,
a rAF watchdog after `LOOP_WATCHDOG_TICKS = 2` frames without an rVFC tick and immediately while paused/ended (only rVFC ticks
upload; `ended`/`paused` is not a stand-down — the last frame stays composited like the export's own end of media; the
watchdog also prevents a 30 fps clip on a 60 Hz display from double-ticking and breaking the probe's strict-monotonic `t`).
A `webglcontextlost` listener on the armed canvas stands down with `contextLost` independent of any tick (one emitting site
shared with the guard). Step 8: on a live, connected context the stand-down ends with one `replayFrame({rest:true})` so the
clean frame is composited; skipped for `canvasRemoved`, `contextLost` and `unflaggedPlayerCall` (that path runs inside the
wrapper and must only write back and forward). `stats()` gains `loopMode`, `videoEnded`.

### 2.6 The seam (consumed by G2, implemented by G3, stubbed by S3)
`window.__OBED_P2_PRESERVE__.glReplay = {version: 1, carried(movieKey) → {video: HTMLVideoElement|null, reason: string|null}, movieKeyOf(v) → string|null, setKeepWarm(v, bool) → void, release(movieKey, {rect}) → {ok: bool, reason: string|null}, note(kind, detail) → void}`. G2 reads NOTHING else from the core (a static test greps the module for `__OBED_P2_PRESERVE__.` followed by anything other than `glReplay`). Semantics G3 owes: `carried` = the pooled, never-mounted decoder of the carried INSTANCE (chosen by captured rect vs the plan's source instance rect; ambiguous ⇒ null, `reason: 'ambiguous'`), `setKeepWarm(v,false)` makes the 200 ms sweep skip `v`, `release` = retire same-asset siblings per instance + `tryRemount` with the destination rect as `__obedRect` (arming §10 a/b). **What the S3 stub proves:** everything inside the module (order-of-install, recording, poster rule, settle, opacity proofs, LIVE, handle contract via the REAL `INPAGE_LIVENESS_JS`, write-back, stand-down ordering, hand-off mechanics via `remountAll` exactly as Q0b measured). **What it cannot prove:** G3's zone semantics (pool-but-never-mount under `preserveAllowedFor`), instance selection, sibling retire, destination-rect remount, `CONTINUITY_VERSION` 5 / sha, P2 census. Q0b n=2 and the hand-back parity gate are re-run after G3 (unchanged from rev 1).

### 2.7 Reason strings (closed, tested)
Stand-down: `planUnreadable, runtimeSeamAbsent, glReplayUnavailable, settleSignalAbsent, sceneMismatch, observerNotArmed, canvasShape, posterAmbiguous, posterUnreadable, frameNotDelimited, contextLost, rvfcUnavailable, videoNotReady, assetUnbound, occlusionTooHigh, unflaggedPlayerCall, frameLengthChanged, glError, writebackFailed`. Normal exit: `canvasRemoved` (note `glreplay-handoff`). Milestones: `glreplay-arm`, `glreplay-live`. Opacity (per slot, note `glreplay-opacity-unproven {slot, reason}`): `count, uniforms, mixfactor, size, mvp, rest-opacity, ablation, identity`. Emitting sites: every reason has exactly one emitting use of its bound constant, except `canvasRemoved` (two: the LIVE `guards()` return and the MutationObserver callback) — enforced by `test_each_reason_is_emitted_from_exactly_one_site`. Debug: `window.__OBED_GL_REPLAY__.debugForceFail = <reason>` (read at that assertion site only; arming §5's fail-closed arm; documented as never a product path).

`GL_REPLAY_VERSION = 1`, `GL_REPLAY_JS`, `js_sha256()`, `validate_gl_replay_entry(runtime_plan) -> dict | None` (exactly one `glReplay` boundary, every field of §2.0 + rev 1's shape checks, `fallback == "retire"`), `gl_replay_script(runtime_plan) -> str` (`""` or `<script id="obed-gl-replay">…</script>\n`, `</script` escaped). ### 2.9 Constants — measured vs assumed (Opus r1 finding 11, recorded 2026-09-22)
Measured: `MVP_TOLERANCE_PX = 1` (opacity §0, worst 0.32 px) · ablation tolerance `ABLATION_GRID_PX + 2` (opacity §1.4) ·
`OCCLUSION_MAX_FRACTION = 0.5` (arming §2) · `SEGMENT_CALL_CAP = 512` (F7 max 125) · `SETTLE_QUIET_TICKS = 3` (max intra-move
clear gap 32.7 ms vs 99.8 ms to `ready`) · `CONTROL_PATCH_PX/CONTROL_INSET_PX/BAND_COLS/BAND_ROWS` (probe) · `GREEN_INSET_PX = 8` (D1(a)).
**Assumptions, no measurement behind them (state in the PR; S3 gates exercise them on the real frame):** `MARKER_BAND_EPSILON = 0.5`
(band-mean difference below which a marker band counts as occluded), `ABLATION_COVERAGE_MIN = 0.8`, `ABLATION_GRID_PX = 4`
(the grid itself, not the tolerance), `MARKER_PATCH_PX = 8`.

**Rest-opacity capture (Opus r3 spec 1, shipped in `33f2f81d`):** `restOpacity[i]` is captured PER DRAW from a clean
capture replay (the value in effect when draw i executes), never per program at end of frame — two draws sharing a program
with different in-frame `Opacity` would otherwise both replay at the last value. Write-back restores once per program the
value the frame last set for it. `stats().programsDistinct` reports whether the real deck exercises the shared case; the
per-slot `opacityAfterProofs` invariant is only load-bearing while it is true. Lesson: on the P2 frame only program 4 (never
re-set in-frame) can reveal a missing `Opacity` write — tests must target slot 4 and dirty the program first.

## 2. Module design

**Python side (`live_gl_replay_js.py`).** Mirrors `live_continuity_js.py`: `GL_REPLAY_VERSION = 1`, `GL_REPLAY_JS = r"""(function(){ ... })();"""`, `js_sha256()`. Plus one builder, **`gl_replay_script(runtime_plan) -> str`**: returns `""` unless the plan has **exactly one** boundary with `action == "glReplay"` whose shape validates (`atScene` int, `movieKey` in `movies`, `fallback == "retire"` literal, `slotSizes` list of `[int,int]`, `slotRects` same length of 4 finite floats, `opacityOverrides` list of `{slot:int < len, opacity: float in (0,1), texW, texH ints == slotSizes[slot]}`); otherwise `""`. On success it returns `<script id="obed-gl-replay">` wrapping `GL_REPLAY_JS` with `</script` escaped like `_continuity_core_script`. The JS reads the entry itself from `window.__OBED_CONTINUITY__` (already installed before it, F1) and re-validates in-page (`planUnreadable` ⇒ install nothing). **`off` guarantee**: the host (G4) calls the builder only when `gl_replay == "auto"` AND `derive_plan(gl_replay=True)` produced a `glReplay` entry; with `off` the builder is never called, the plan is today's (G1 decision B), and the served HTML has no `obed-gl-replay` tag — a test asserts `"gl" not in program_html` byte-wise. Nothing in the module is imported by `live_host.py` at all in G2.

**JS structure** (one IIFE, no minified names, everything under `window.__OBED_GL_REPLAY__ = {version, state, events[], notes[], standDowns[], stats()}`):

1. **Install (IDLE, before player load).** Guard: `if (!window.__OBED_CONTINUITY__) return; if (window.__OBED_GL_REPLAY__) return;` Find the single `glReplay` entry; else return (nothing installed). Wrap `HTMLCanvasElement.prototype.getContext` (records `canvas→ctx`), and every function on `WebGLRenderingContext.prototype` / `WebGL2RenderingContext.prototype` (lift the harness loop incl. the `SKIP` regex, but track `createTexture`, `bindTexture`, `useProgram`, `activeTexture`, `texImage2D/texSubImage2D`, `pixelStorei`, `uniform1f`, `drawElements/drawArrays`, `clearColor/clear`). Wrapper hot path: `if (replaying > 0 || !(state.recording || state.live)) return orig.apply(this, arguments);` — one integer test at idle. MutationObserver on `#stage` (childList+subtree) armed at install **inside a `DOMContentLoaded`/`#stage`-present retry**, and asserted armed before any upload (`observerNotArmed`). Idle before `#stage` exists is the only allowed deferral.
2. **ARM-PRE** (hash enters `atScene−1`, read via the same `/^#?(\d+)/` rule as the core; polled from the rVFC/observer path, never `hashchange`): require the seam `window.__OBED_P2_PRESERVE__.glReplay` (§3) and its `pooledFor(movieKey)` → exactly one `HTMLVideoElement` with `readyState ≥ 2`, `movieAssetKey(currentSrc) === movieKey` via the seam's `movieKeyOf(v)` (`assetUnbound` otherwise, never "first video"), `typeof requestVideoFrameCallback === 'function'` (`rvfcUnavailable`). Context: exactly one context whose `canvas.id === '0-canvas'`... **no** — the id is `<transitionObjectID>-canvas`; assert `/^\d+-canvas$/`, `#stage.contains(canvas)`, `isConnected` (`canvasShape`). Poster: the first upload with signature `{srcType canvas, w×h == slotSizes[movieSlot], RGBA/UNSIGNED_BYTE, flipY true, premul true}` where `movieSlot` = the slot whose `slotSizes` equals the pooled video's poster size and whose `slotRects` IoU with `movies[movieKey].footprint` ≥ 0.75; a second signature match on the same context ⇒ `posterAmbiguous` (A1). Start recording into a ring buffer (cap 512 calls/segment, 2 segments retained; overflow ⇒ `frameNotDelimited`). Per-`clear` upload of the pooled video into the poster texture with the harness's `uploadInto` (pixelStore/binding save-restore), under `replaying++`.
3. **ARM-POST** (settle = the host's settle signal is not in-page; use: no player `clear` for ≥ 250 ms after `hash == atScene`, measured frame gap ≪ 250 ms — **state this constant as unmeasured, report-only latency**): stop recording; last segment must start with `clearColor,clear` and be non-empty (`frameNotDelimited`); snapshot poster via FBO readback (`posterOf`, requires `FRAMEBUFFER_COMPLETE`, else `posterUnreadable`); marker swap 8×8 black/white → `markerBands`, occluded ≤ 50 % (`occlusionTooHigh`); restore poster; `readPixels` baseline. **Opacity proofs** (per opacity plan §2, per-slot, never a stand-down): `nDraws === slotSizes.length` else all slots unproven `count`; per draw i: program via recorded `useProgram`, `getActiveUniform` set ⊇ `{Opacity, mixFactor, MVPMatrix, Texture, Texture2}` else `uniforms`; `mixFactor` from recorded `uniform1f` on that program (1 ⇒ unit of `Texture`, 0 ⇒ unit of `Texture2`, else `mixfactor`); sampler-visible texture's last upload size === `slotSizes[i]` else `size` (duplicate-size rule: only slots with an override are blocked); MVP decode of `(0,0)-(texW,texH)` vs `slotRects[i]` within 1 px/edge else `mvp`; for override slots: `getUniform(prog, loc) === 1.0` else `rest-opacity`; ablation footprint (replay minus draw i, diff on 4-px grid vs `slotRects[i]` ± (grid+2) px) else `ablation`; α=0 identity (patch 0 byte-equal to ablation) else `identity`. Every failure ⇒ note `glreplay-opacity-unproven {slot, reason}` and the override is dropped. Capture `progOpacityBefore[i]` for all draws.
4. **LIVE.** `rVFC` tick: guards (canvas connected & in `#stage`, `!isContextLost()`, frame length unchanged, `getError() === 0`, no unflagged call since last tick) ⇒ else STANDDOWN; upload; replay the recorded frame, issuing `uniform1f(loc_i, override_i)` **inside `replaying`** immediately before draw i (after any recorded `uniform1f` for that program); one `sample()` read in the same task; publish the handle on the first successful tick. Unflagged player call inside the wrapper ⇒ write-back `progOpacityBefore` **before forwarding** the call, then STANDDOWN.
5. **STANDDOWN.** Triggered by removal of the armed canvas from `#stage` (observer), any LIVE guard, or `disable()`. Synchronous: stop loop, write back `Opacity` for every touched program (skip with `isContextLost()` asserted true; any other `uniform1f` failure ⇒ hard reason `writebackFailed`), restore poster, unpublish the handle (`delete window.__OBED_GL_ORACLE__`), then call the seam's `release(movieKey, {rect: slotRects[movieSlot] as {x,y,w,h}})` which hands the pooled decoder to `tryRemount` at the DESTINATION rect (G3 implements). Record `latencyFromMutationMs` (report-only in v1, per arming §9).
6. **Notes / `notCarried`.** Every stand-down pushes `{kind:'glreplay-standdown', reason}` into both `__OBED_GL_REPLAY__.events` and, via the seam, the core's `note()` stream (so P2/probe evidence sees it). Reason strings (closed set, tested): `planUnreadable, runtimeSeamAbsent, glReplayUnavailable, observerNotArmed, canvasShape, posterAmbiguous, posterUnreadable, frameNotDelimited, contextLost, rvfcUnavailable, videoNotReady, assetUnbound, occlusionTooHigh, unflaggedPlayerCall, frameLengthChanged, glError, writebackFailed, canvasRemoved` (the last is the *normal* exit, noted as `glreplay-handoff`, not a stand-down). Arm/live milestones: `glreplay-arm`, `glreplay-live`.
7. **Oracle handle** (published only in LIVE): `{gl, canvas, video: pooled element, epoch (incremented on every record), sceneId: atScene, instanceId, rect, canvasId: canvas.id, sample(n), markerBands(), pause(), resume()}`. `sample(n)` resolves after n **distinct** ticks (rVFC while playing; rAF-driven replay+read while paused, so the paused control yields 24 static samples), each `{t: performance.now(), ms, vt, mediaTime, bands[128], control, green, greenRGB, glErr}`; `markerBands()` re-runs the swap in the current armed state and returns `{dark, light, epoch}`; `pause()` sets the seam hold and pauses the video; `resume()` clears it and plays. Geometry in drawing-buffer px: movie rect = `slotRects[movieSlot]`; control = `CONTROL_PATCH_PX` square inset `CONTROL_INSET_PX` at the canvas top-left (JS literals asserted equal to `p2_verdict` constants by a Python test); green = the front-most overlapping slot's settled rect minus the movie rect (largest remainder, 8 px inset — fixture gives the top band ≈ opacity plan's `800,690,330×90`); if no overlapping slot exists, `green`/`greenRGB` are `NaN` so the scorer goes INCONCLUSIVE rather than DEAD. **`rect`/`instanceId` cannot be produced from G1's entry (F5)** — see §6.
