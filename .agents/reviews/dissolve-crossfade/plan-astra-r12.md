1. **Major — CLASS: flag integrity — §3.1, §3.3.**  
   **Scenario:** After Chrome is calibrated as `snap`, page code assigns `window.__obedCalib = Object.freeze({placement:"frac",tone:null})`. D4 accepts it; the fingerprint remains unchanged. Page code can also make that property non-writable/non-configurable, preventing the host’s subsequent clear. I reproduced both operations in Node. Freezing the object does not protect its containing property. [ECMAScript specification](https://tc39.es/ecma262/multipage/fundamental-objects.html#sec-object.freeze)  
   **Exact fix:** Make calibration private state initialized invalid in each document. Expose, at most, a non-configurable getter; retain the updater through a host-only CDP remote handle established before export scripts execute. Test replacement, deletion, accessor substitution, predefinition and failed revocation. The wrong-rule controls must use the privileged test channel, rather than demonstrate that production page code can override admission.

2. **Major — CLASS: output isolation — §3.3, §13(a).**  
   **Scenario:** Start a deck while managed OBS already owns the connected DeckLink output. The browser source is visible and DeckLink has `auto_start: True`. Host “hide” only sets `#body` opacity to zero, whereas `probe.js` appends its opaque box directly to HTML `body`, outside that hidden subtree. The calibration box therefore reaches program before `show`. On HDMI, its later insertion at the black overlay’s same maximum z-index likewise defeats the overlay. See [host hiding](/Users/anyhowclick/Desktop/work/obed-edom/.claude/worktrees/brave-goodall-bd9851/src/obed_edom/live_host.py:425) and [managed output configuration](/Users/anyhowclick/Desktop/work/obed-edom/.claude/worktrees/brave-goodall-bd9851/src/obed_edom/managed_obs.py:106).  
   **Exact fix:** Require a verified output gate independent of the page being captured. Without that gate, skip calibration. Specify separate HDMI and managed-OBS mechanisms, cleanup on every exit, and output-capture controls proving that neither startup nor failed recalibration exposes the probe.

4. **Major — CLASS: calibration lifecycle — §3.3, §10.5, §13(a–b).**  
   **Scenario:** CDP disconnects and reconnects while the document survives. Its frozen object survives too; an unchanged fingerprint never triggers the specified clear. The next take therefore remains enabled, contradicting the promised on-air reconnect skip. Separately, a reload after the last screenshot but before an untargeted evaluate can install the old result into the replacement document. Current tests cover neither sequence.  
   **Exact fix:** Define explicit invalid/probing/valid states, bind results and installation to the same target and unique execution context, invalidate before recalibration and immediately upon reconnect before commands resume, and reject late results. Add lifecycle controls starting from a valid flag: reconnect, reload/source refresh, navigation during commit, changed/unreadable fingerprint and failed re-probe. Define the operator recalibration command and its route—the plan currently says `web/live.py` stays unchanged. Treat unchanged-fingerprint GPU resets as an explicit unresolved coverage limit, not as fulfilled decision-13 reset handling.

5. **Major — CLASS: acceptance coverage — §3.2, §9.0.2, §9.2.**  
   **Scenario:** A fractional-draw regression omits the clipped-region `dx`/`dy` adjustment. Unclipped CEF P2/DSK positives and both wrong-rule negatives can still behave as expected, while an admitted movie with a fractional ancestor clip draws the wrong source region. The Chrome matrix exercises `snap`; it cannot qualify CEF’s new second draw. The underlay can remain fully opaque throughout, so the alpha scan does not detect this RGB error.  
   **Exact fix:** Add CEF `frac` cases for unclipped, fractional-x-clipped and fractional-y-clipped regions at the admitted DPR/origin, including foreground crossing those boundaries. Require edge-inclusive reference scoring, `perfect`, omit twins and a deliberately wrong fractional-offset control. Preserve the whole-backing alpha scan after both movie draws and before foreground redraw.
