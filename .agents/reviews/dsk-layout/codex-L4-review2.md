REVISE

Prior findings 1–4 are substantially addressed, but three safety gaps remain.

1. **High — reuse can mutate a mask shared with an unrelated drawable.** `src/obed_edom/dsk_pill.py:394` resolves the candidate’s mask and updates it without proving that the mask belongs exclusively to that image. A Media-tagged image—or an untagged fingerprint match—could reference the layout mask or another image’s mask; the target verifies successfully while every other user of that mask is altered. Fix: before mutation, require the image to live in the target slide member, require `mask.super.parent.identifier == image_id`, require the mask to live in the same member, and confirm no other image references that mask ID.

2. **Medium — mint metadata verification is global and incomplete.** `src/obed_edom/dsk_pill.py:588` accepts registrations found in any component and only requires one data reference for the image. Verification therefore passes if UUID entries land in the wrong component, only one of the four expected data references survives, the reference count is wrong, the required cross-component style reference disappears, or `lastObjectIdentifier` is not persisted. Fix: carry the target component ID, expected data IDs, style/component pair, and final counter in `_Expected`; verify exact registrations in that component, including every data ID with `{objectIdentifier: image_id, count: 1}`.

3. **Medium — verification does not prove that only the mask changed.** `src/obed_edom/dsk_pill.py:542` checks composed geometry and two size fields, but not the image’s raw geometry/angle or style reference. A changed image geometry that still composes to the expected frame, or a dropped/conflicting style, can pass. Additionally, `src/obed_edom/dsk_pill.py:184` and `:568` compare mask types only to the layout, allowing both missing values to pass. Fix: retain and compare the complete immutable image fingerprint after reread, and require the concrete mask type `kTSDRoundedRectangle` for both source validation and output verification.
