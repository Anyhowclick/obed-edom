## Spec

1. **(new class, HIGH) A stand-down before the video resolves never reaches `seam.release`.** `:739` guards with `if (state.seam && state.video)`. `state.video` is only set by `resolveVideo()` on the first per-clear upload, so `canvasShape`, `settleSignalAbsent`, `sceneMismatch`, `posterAmbiguous`, `posterUnreadable`, `frameNotDelimited`, `assetUnbound`, `rvfcUnavailable`, `occlusionTooHigh` and `debugForceFail` on any of them end with the decoder pooled, never mounted, never retired — a blank movie on the destination slide. §2.5 step 6 is unconditional. **Fix:** replace `if (state.seam && state.video){` with `if (state.seam){` at `:739`.
2. **(new class, HIGH) `observerNotArmed` does not stand down.** `:986` routes it through `refuseInstall`, which only pushes the reason and sets `RETIRED` (`:126-132`) — no write-back, no poster restore, no `release`. §2.7 lists it under *Stand-down*, not install refusal, and by `:986` the seam is not yet resolved either. **Fix:** move the observer arm to the top of `preflight()` (`:916`) as `if (!assertOr('observerNotArmed', armObserver(), null)) return false;`, placed after the `runtimeSeamAbsent` assert, and delete `:986`. Keep only `planUnreadable` and `glReplayUnavailable` on `refuseInstall`.
3. **(new class, MED-HIGH) ARM-PRE preconditions are checked once, not polled, and stand down before a context exists.** `:943-946` calls `preflight()` exactly on the IDLE→ARM-PRE edge and `assertOr` fires immediately. §2.2: "each polled on rAF while in ARM-PRE, none a stand-down until a context exists". A `__obedLive` or seam that is defined one frame after the hash flip is a permanent, wrong stand-down. **Fix:** in `preflight()` change each `assertOr(...)` / `requireVideoFrameCallback(...)` to record the missing item and return `false` without standing down while `state.gl` is null; call `preflight()` from the ARM-PRE branch on every tick, and only convert the outstanding item into `assertOr(reason, false)` once `onContextCreated` has set `state.gl`.
4. **(new class, MED-HIGH) `settleToHashMs` is unreachable.** `:959-960` does `armPost(); return;` without rescheduling, so the `poll` rAF chain dies at ARM-POST and the `LIVE` branch at `:962-964` never runs. §2.3 and §4 gate (2) both require the value. **Fix:** replace `armPost();\n        return;` at `:959-960` with `armPost();` (drop the `return`, letting the tail `requestAnimationFrame(poll)` at `:965` run), and change the `else if` at `:948` to also skip while `state.phase === 'ARM-POST'`.
5. **(new class, MED) `pause()`/`resume()` spawn duplicate loops.** `:772` and `:781` start a loop unconditionally; two `pause()` calls leave two rAF chains and two `resume()`s leave two rVFC chains, doubling uploads and `readPixels` per frame for the rest of LIVE. **Fix:** add `loopGen: 0` to `state`, bump it at the head of `startLiveLoop`/`startPausedLoop` (`var gen = ++state.loopGen;`) and make each `step` return early unless `gen === state.loopGen`.
6. **(new class, MED) A pending `sample(n)` never settles after a stand-down.** `collect()` (`:788-792`) stores an unresolved promise; `standDown` stops the loop and deletes the handle without touching `state.collectors`, so the probe's `await handle.sample(24)` hangs. **Fix:** in `standDown`, immediately after `state.hot = false;` (`:706`), add `state.collectors.forEach(function(c){ c.resolve(c.out); }); state.collectors = [];`.
7. **(closed class re-applied — paint-oracle r3 ROI clamping, MED) `toBuffer` can emit an out-of-range ROI.** `:383-390` clamps `w`/`h` against the full canvas without subtracting the origin, and clamps `x` to `c.width - 1` afterwards; `y` is not clamped from above. The ablation ROI at `:646-647` dilates by 8 px, so any slot rect within 8 px of an edge yields `x + w > canvas.width` or `y + h > canvas.height` ⇒ `INVALID_VALUE` ⇒ a spurious `glError` stand-down in LIVE. **Fix:** rewrite the body as `var x = Math.min(Math.max(0, Math.round(r.x)), c.width - 1); var yTop = Math.round(r.y); var y = Math.min(Math.max(0, c.height - (yTop + Math.round(r.h))), c.height - 1); return {x: x, y: y, w: Math.max(1, Math.min(Math.round(r.w), c.width - x)), h: Math.max(1, Math.min(Math.round(r.h), c.height - y))};`
8. **(edge case, MED) A player GL call during ARM-POST is silently tolerated.** `:226` only refuses when `state.phase === 'LIVE'`. ARM-POST (`:861-890`) paints the poster texture, replays three times per slot and reads back; a player draw landing inside it corrupts every proof without any reason string. **Fix:** change `:226` to `if (state.phase === 'LIVE' || state.phase === 'ARM-POST'){`.
9. **(new class, MED) `unflaggedPlayerCall` cannot be forced.** `:227` calls `standDown` directly, bypassing `assertOr`, so `debugForceFail = 'unflaggedPlayerCall'` never fires and §4 gate (6) cannot cover it. **Fix:** in `tickOnce` (`:820`) add, right after `if (state.down) return false;`, `if (!assertOr('unflaggedPlayerCall', API.debugForceFail !== 'unflaggedPlayerCall', {forced: true})) return false;` — keeping the literal at its single real site via `assertOr`'s own `debugForceFail` test rather than a second comparison. (Simplest alternative: route `:227` through `assertOr('unflaggedPlayerCall', false, {call: name})`, which already honours the force arm.)
10. **(edge case, MED-LOW) Write-back touches programs we never overrode.** `state.opacityBefore[i]` is captured for every complete draw program (`:616-618`), and `standDown` (`:715-720`) issues `useProgram` + `uniform1f` for each. §2.5: "for every program we issued an override on". **Fix:** change the guard at `:717` to `if (!prog || !loc || !loc.Opacity || before == null || state.overrides[i] == null) continue;` and capture `overrides` before `proveOpacity`'s cleanup, or keep a `state.overrodeSlots` set written at `:671`.
11. **(new class, LOW — traceability) Three unmeasured constants.** `:689` `Math.abs(dark[i] - light[i]) <= 0.5` is the occlusion decision threshold with no citation; `ABLATION_COVERAGE_MIN = 0.8` (`:42`) and `ABLATION_GRID_PX = 4` (`:40`) likewise (§2.3 measures only the *tolerance* "grid step + 2"). `paintTexture`'s `n = 8` (`:288`) is fine but undocumented. **Fix:** hoist the `0.5` to `var MARKER_BAND_EPSILON = 0.5;` beside the others and add one line to plan §2.3 recording the measurement (or the F7 20/128 occluder margin) that each of the three derives from; if none exists, say so in the PR as a stated assumption.
12. **(edge case, LOW) `handle.epoch` is frozen at publish while `markerBands()` returns the live `state.epoch`.** `:757` vs `:765`. v1 records once so they cannot diverge today, but §2.4's "`epoch` incremented on every record" makes the frozen copy the wrong one if a second record is ever added. **Fix:** no code change in v1; add `epoch` to the S2 test's "single-record invariant" list and note in the PR that a second record must convert `:757` to a getter.
13. **(edge case, LOW) `settleGapMs` measures the last player *call*, not the last `clear`.** `:953` uses `state.lastPlayerAt`, set on every wrapped call (`:231`). §2.3 says `t(ready) − t(lastClear)`; the measured delta is 0.1 ms (last clear 1625.5, last draw 1625.6), so the number is still comparable, but the plan and the field disagree. **Fix:** either set a separate `state.lastClearAt = now()` under `if (name === 'clear')` at `:232` and use it at `:953`, or amend plan §2.3 to read "t(ready) − t(last player GL call)".
14. **(edge case, LOW — G1b) Duplicate destination rects pick the first silently.** `live_continuity.py:894-896` returns on the first `rect == wanted`; two instances of one asset with byte-identical rects give a possibly wrong `asset#index`, and the probe's exact-float check would still pass. **Fix:** collect all matches and `return None` when `len(matches) != 1`, so `to_runtime` refuses (`Unsupported`) rather than guessing.
