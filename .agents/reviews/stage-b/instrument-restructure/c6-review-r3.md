## medium · whole · score_arm turns malformed or missing sample evidence into an empty valid row list, so the sample contract no longer rejects it and replay can report a fabricated reproduction
`scripts/live_continuity_probe.py:4549` · class: new class

**Scenario.** When `samples` (or `sampleRows`) is not a list of dicts, `_capture_samples` returns `[]`. A missing or non-list `samples` key is coerced the same way, and it also adds a fabricated `sampleRows: []` key. `contract.sample_rows([])` passes, so `score_verdicts` never sees the bad rows. Before C6, `rescore_generated` called `score_verdicts(entry["samples"], ...)` directly. The contract returned `row:object at samples[N]`, every verdict was `contractRejected`, and `ok` was False. I reproduced the new behaviour in a single process using `_stored_artifact(evidence=True)` with `groundTruth` removed, `5` appended to arm A's samples, and the stored LEGACY_SAMPLE_VERDICTS and refused1to2 set to `{verdict: None}`. Result: `rescore_generated(...)` returned `ok=True` with counts `{reproduced: 16, differ: 0, notRederivable: 0, contractRejected: 0}`. Calling `score_verdicts` on the same rows returns `inconclusive: evidence contract: row:object at samples[216]`. With P2 legacy ground truth present, the same artifact makes `score_boundaries(entry["samples"])` raise AttributeError, because the rejected-arm guard is never set. If stored verdicts are non-None, the outcome is reported as `differ` instead of `contractRejected`. Fresh capture paths cannot hit this because `drain_samples` raises on non-dict rows. Replay of a stored artifact can, which breaks the plan's acceptance rule of zero fabricated historical successes. This is a new class: an input-shape coercion inside the new scoring interface.

**Fix.** Make `_capture_samples` stop coercing. Return the raw `samples` value, or `sampleRows` only when that key is present. When it is not a list of dicts, `score_arm` should run `contract.first_errors(contract.sample_rows(raw, schema=schema))` and return `_contract_inconclusive(errors)` for every spec id, with aliases and the verdict table. It should skip the wrap, stage-map, stage-fit and paint summaries and never add a `sampleRows` key. Do not hand the raw value to `score_verdicts` directly, because its `samples` parameter is typed `list[dict]`. Cover this by parametrizing the existing `test_known_bad_evidence_outside_the_contract_is_never_reproduced` with a case that appends a non-dict row (for example `5`). Assert `contractRejected == 4`, `ok is False` and `equalsLegacyScorer is None`, and keep `groundTruth` present so the AttributeError path is exercised too. No new test function is needed.
